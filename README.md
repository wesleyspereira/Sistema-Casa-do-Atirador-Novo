# Casa do Atirador — versão camuflada

Projeto React + JavaScript + CSS com Vite.

## Rodar o projeto

```bash
npm install
npm run dev
```

## Alterações desta versão

- Tema camuflado escuro aplicado em todo o site.
- Header limpo e com logo oficial.
- Hero reorganizado e responsivo corrigido.
- Cards, serviços, experiência, sobre e footer ajustados para a mesma identidade visual.
- Logo oficial adicionada ao footer.
- Texto “Projeto visual premium.” removido.
- CSS duplicado e regras responsivas fora de media queries removidos.

## Principais arquivos

- `src/styles/global.css` — tema global e camuflado base.
- `src/styles/header.css` — header.
- `src/styles/hero.css` — hero.
- `src/styles/sections.css` — categorias, produtos, serviços, experiência e sobre.
- `src/styles/footer.css` — footer.
- `src/styles/responsive.css` — tablet e mobile.
- `src/components/Footer.jsx` — footer com logo oficial.
